# GlowMate ✨

GlowMate is a Windows Forms desktop application developed using C# and .NET Framework. The system provides product and category management, user authentication, customer feedback, and administrative functionalities.

## Features

- User registration and login
- Product and category management
- Admin dashboard
- Customer feedback management
- Product browsing
- Report generation
- Database integration

## Technologies Used

- C#
- Windows Forms
- .NET Framework 4.7.2
- SQL Server LocalDB
- Visual Studio

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/ridmi18/GlowMate.git
   ```
2. Open `GlowMate.sln` in Visual Studio.
3. Ensure .NET Framework 4.7.2 and SQL Server LocalDB are installed.
4. Configure the `GlowMate` database and its required tables.
5. Build and run the application.
